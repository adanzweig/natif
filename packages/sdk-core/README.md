# @be-natif/core

Platform-free core of Natif: model selection, schema-validated output, knowledge grounding, consented cloud fallback.

```bash
Used by @be-natif/web, @be-natif/react-native and @be-natif/expo. Install one of those instead.
```

Part of **Natif**, the on-device AI SDK: describe the task, not the model. Natif picks the model that fits each device, runs it locally and validates the output.

- Playground (runs in your browser): https://benatif.com/playground/
